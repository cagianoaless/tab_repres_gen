# Frozen-panel aggregation sensitivity

This analysis compares the full pointwise readout with native frozen-score
ranking at 200 context examples per class. It reports the prespecified
equal-provenance-family fixed-panel estimand alongside an equal-dataset
sensitivity and leave-one-family-out values.

The mean contrast is +0.0064 under equal-family weighting and -0.0346 under
equal-dataset weighting. With a 0.005 practical tie band, the dataset-level
counts are 5 wins, 4 ties, and 48 losses. Excluding the MetaFam family changes
the equal-family contrast to -0.0414.
