# Fixed-Panel Diagnostics

Exact representation diagnostics and directional sensitivities across all 57
GraphLog worlds.

| File | Content |
|---|---|
| `representation_by_world.csv` | ceilings, singleton mass, collisions, support, and chance |
| `representation_by_world_and_length.csv` | diagnostics by OOD length |
| `representation_summary.csv` | equal-world representation summary |
| `fixed_panel_sign_sensitivity.csv` | paired directional sensitivity |
| `summary.json` | input identity and aggregate summary |

The sign calculation is a fixed-panel sensitivity, not population inference.
