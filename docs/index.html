Overview

We study relational generalisation through the interface that turns graph-structured information into tabular examples. The experiments separate the graph-to-table encoder, labelled context constructor, and decoder, and test how conclusions change when these components change.

The repository contains the end-to-end reproduction pipeline for the paper, including graph-to-table feature construction, context generation, decoder execution, filtered ranking evaluation, statistical analyses, and lightweight reference outputs.

57-KG representation

Full32 = Local18 + frozen ULTRA score1 + Global13

ULTRA score1 Frozen score from the pinned ULTRA-4G model.
Global13 PageRank, component, spectral heat, and diffusion features.

Reproducibility

The artifact documents the complete path from public datasets and pinned model dependencies to the reported analyses. Large model weights and multi-gigabyte generated intermediates remain external, while source identities, reference outputs, and execution metadata are checksummed.
